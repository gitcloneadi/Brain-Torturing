# [Search in Rotated Array 2](https://www.geeksforgeeks.org/problems/search-in-rotated-array-2/0)
Difficulty Level : Difficulty: Medium

Given a sorted and rotated array 
arr[]
 and a target 
key
. Check whether the key is present in the array or not.


Note:
 The array may contains duplicate elements.


Examples:


Input: 
arr[] = [3, 3, 3, 1, 2, 3], key = 3

Output
: true

Explanation
: 3 is present in the array.


Input
: arr[] = [4, 5, 8, 1, 1, 1, 2], key = 6

Output
: false

Explanation
: 6 is not present in the array.


Constraints
:
1 ≤ arr.size() ≤ 10
6
0 ≤ arr[i], key ≤ 10
8
